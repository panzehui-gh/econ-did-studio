# Building the LaTeX reports

The English (`report.tex`) and Japanese (`report_ja.tex`) versions include
vector PDFs generated by the validation commands.

```bash
econdid validate --replications 20 --output docs/validation
econdid verify --replications 50 --dirty-replications 30 --output docs/cross_validation
tectonic report/report.tex --outdir report
# Compile report/report_ja.tex from the report directory so ../docs resolves.
```

Before submission, replace the blank student name and ID rules in the selected
source and confirm the repository URL. Both versions are designed to remain at
most two A4 pages.
