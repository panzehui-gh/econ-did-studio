# Building the report

The final report is written in LaTeX and includes the vector PDF generated by
the validation command.

```bash
econdid validate --replications 20 --output docs/validation
tectonic report/report.tex --outdir report
```

Before submission, replace the blank student name and ID rules in `report.tex`
with the required details and confirm the repository URL. The compiled report
must remain at most two pages.
